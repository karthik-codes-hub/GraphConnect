
# GraphConnect – BFS/DFS & Connectivity Lab

An interactive graph visualization platform designed to help students understand graph traversal algorithms and graph connectivity through step-by-step visual demonstrations.

## 🚀 Live Demo

[GraphConnect – Try it Live](https://graphconnect-bfs-dfs-visualizer-44dxam725-gopi-bec7.vercel.app/)

## 📌 Project Overview

GraphConnect is an educational web application that visualizes fundamental graph algorithms, including Breadth-First Search (BFS), Depth-First Search (DFS), and graph connectivity.

The platform provides an interactive environment where users can explore graph structures, understand traversal processes, and observe how different algorithms visit vertices and edges.

## ✨ Key Features

- **Interactive Graph Visualization:** Explore graph structures visually.
- **Breadth-First Search (BFS):** Visualize level-by-level graph traversal.
- **Depth-First Search (DFS):** Understand depth-based graph traversal.
- **Graph Connectivity:** Analyze whether vertices are connected.
- **Step-by-Step Execution:** Follow algorithm execution visually.
- **Educational Interface:** Learn graph concepts through interactive demonstrations.
- **Real-Time Visualization:** Observe changes during algorithm execution.

## 🧠 Algorithms Implemented

### 1. Breadth-First Search (BFS)

BFS is a graph traversal algorithm that explores vertices level by level using a queue data structure.

**Time Complexity:** O(V + E)

**Space Complexity:** O(V)

### 2. Depth-First Search (DFS)

DFS explores a graph by going as deep as possible along each branch before backtracking. It uses recursion or a stack.

**Time Complexity:** O(V + E)

**Space Complexity:** O(V)

### 3. Graph Connectivity

Graph connectivity determines whether there is a path between vertices in a graph.

A connected graph is a graph in which every vertex can be reached from every other vertex.
